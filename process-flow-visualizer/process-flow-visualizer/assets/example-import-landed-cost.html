Script Logic

Custom Allocation Script — Pipeline

STEP A

Gather

ดึง shipment + linked PO lines + cost components ที่ตั้งหนี้แล้ว ตรวจว่า cost pool ครบ

STEP B

Compute Factor

คำนวณสัดส่วนของแต่ละ line ตาม basis ที่เลือก (Σ factor = 100% ต่อ component)

STEP C

Allocate

allocated = pool × factor ใช้ rounding adjustment กับ line สุดท้ายกัน error สะสม

STEP D

Check Period

ตรวจ Accounting Period ของ Item Receipt ก่อนเขียนกลับ — เป็นตัวตัดสินปลายทาง

คำศัพท์ · Glossary

Incoterm

ข้อตกลงสากลที่ระบุว่าผู้ซื้อ/ผู้ขายรับผิดชอบค่าใช้จ่ายและความเสี่ยงช่วงไหน (EXW, FOB, CIF, DDP ฯลฯ) — กำหนดว่า component ไหนเข้า cost pool

Cost Pool

กลุ่มค่าใช้จ่ายนำเข้าทั้งหมดของ shipment (freight + duty + insurance + fee) ที่จะถูกกระจายลงต้นทุนสินค้า

Landed Cost

ต้นทุน “ถึงคลัง” จริง = ราคาสินค้า + ค่าใช้จ่ายนำเข้าที่กระจายแล้ว

Allocation Basis

เกณฑ์กระจายต้นทุน — by Value / Weight / Volume (CBM) / Quantity เลือกต่อ component ได้

Item Receipt (IR)

เอกสารรับสินค้าเข้าคลังใน NetSuite — มูลค่า ณ จุดนี้เป็นต้นทุนฐานก่อนเติม landed cost

IRNB

Inventory Received-Not-Billed — บัญชีพักของที่รับเข้าแล้วแต่ยังไม่ตั้งหนี้ vendor

Landed Cost Clearing

บัญชีพักค่าใช้จ่ายนำเข้า ก่อน allocate เข้า inventory — เมื่อ allocate ครบควรเหลือศูนย์

Vendor Prepayment

เงินจ่ายล่วงหน้า/มัดจำให้ vendor ลงเป็นสินทรัพย์ก่อน แล้วนำมาตัดกับ Vendor Bill ภายหลัง

3-way match

การกระทบ PO ↔ Item Receipt ↔ Vendor Bill ให้ตรงกันก่อนตั้งหนี้/จ่ายเงิน

Accounting Period

งวดบัญชี เมื่อ ปิดงวดแล้วแก้เอกสารในงวดนั้นไม่ได้ (กันการย้อนแก้ตัวเลขที่ปิดบัญชีไปแล้ว) — landed cost จึงต้องลง adjustment ในงวดที่ยังเปิดแทน

CBM

Cubic Meter — ปริมาตรสินค้า ใช้เป็นเกณฑ์กระจายค่า freight

THC

Terminal Handling Charge — ค่าภาระหน้าท่า

OPTION

ป้ายบอกว่าขั้นตอนนั้นเป็น “ทางเลือก” ไม่จำเป็นทุกดีล (เช่น มัดจำ ขึ้นกับ payment terms)

Period Gate

ด่านตรวจสถานะงวดใน allocation script: งวดเปิด → เขียนกลับ IR; งวดปิด → ลง adjustment งวดที่เปิด
